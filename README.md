# Django Project

A basic Django project serving as a foundation for building web applications with Django.

## Features

- Django project structure (`manage.py`, `settings.py`, etc.)
- Ready for custom app development
- Minimal setup to get started

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/Abdullah-69-dot/Django-project.git
    cd Django-project
    ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Run migrations and start the server:
    ```bash
    python manage.py migrate
    python manage.py runserver
    ```
